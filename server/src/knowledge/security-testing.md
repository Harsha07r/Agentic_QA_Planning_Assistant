# Security Testing

## Threat modeling
- Identify common threats such as injection, authentication bypass, and data leakage.
- Evaluate the security posture of APIs, forms, and storage layers.
- Align security tests with the OWASP Top Ten.

## Validation and sanitization
- Ensure all input is validated server-side, not only in the UI.
- Use safe parsing and escape outputs when generating serialized data.
- Check permissions on sensitive operations and error messaging.

## Test automation
- Include automated scans for common vulnerabilities.
- Add targeted security tests for authentication, authorization, and session handling.
- Document security test results and remediation steps.
