# API Testing

## Contract validation
- Verify response schemas against API contracts.
- Confirm required fields, data types, and status codes match expectations.
- Test both successful and failure responses for each endpoint.

## Test coverage
- Cover edge cases such as invalid input, missing authentication, and rate limits.
- Validate idempotent behavior for endpoints that should be repeatable.
- Include data-driven tests for parameter combinations and query filters.

## Performance checks
- Run lightweight load tests on critical API paths.
- Ensure response latency stays within acceptable service level targets.
- Monitor backend error rates and request throughput during test runs.
