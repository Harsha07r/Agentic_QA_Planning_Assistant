# QA Guidelines

## Planning quality coverage
- Define test objectives before writing cases.
- Prioritize tests based on business risk, user journeys, and recent failure patterns.
- Keep acceptance criteria aligned with QA requirements and product goals.

## Test case hygiene
- Use clear, concise titles and steps.
- Avoid overly broad test cases; each should verify a single behavior.
- Update cases when requirements change and keep descriptions current.

## Regression strategy
- Maintain a regression suite for core functionality.
- Automate high-value, repeatable smoke and regression cases.
- Review flakiness regularly and remove or refactor unstable tests.
